# Mika Desktop Pet

A small Godot desktop-pet starter project.

## Requirements

- Godot 4.7 or a compatible later Godot 4.x release.
- Desktop operating system supported by Godot.

## Run

1. Open Godot Project Manager.
2. Choose **Import** and select this repository's \`project.godot\`.
3. Open the project and press **F6** or **F5** to run the main scene.

## Current functionality

- A small always-on-top desktop window.
- A simple Mika panel and greeting button.
- A minimal scene/script structure that can be extended with animations, moods, and desktop interactions.

## Project structure

- \`project.godot\` - project and window configuration.
- \`Main.tscn\` - main scene.
- \`Main.gd\` - basic interaction logic.
- \`icon.svg\` - project icon.

The project intentionally has no external editor plugins enabled.
